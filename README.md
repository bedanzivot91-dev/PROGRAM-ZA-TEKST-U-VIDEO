# PROGRAM ZA TEKST U VIDEO

Kompletan paket programa v15.6.0 iz ovog projekta.

## Pokretanje na Windowsu

1. Preuzmi ceo repozitorijum preko **Code → Download ZIP**.
2. Raspakuj ZIP.
3. Pokreni **SASTAVI-PROGRAM.bat**.
4. Posle sastavljanja:
   - installer je u folderu `INSTALLER`;
   - portable verzija je u folderu `PORTABLE`.

Izvorni kod, testovi i dokumentacija nalaze se u folderu `SOURCE`.

EXE fajlovi su podeljeni u delove samo zbog GitHub ograničenja veličine pojedinačnog fajla. `SASTAVI-PROGRAM.bat` ih sastavlja nazad bez izmene sadržaja i prikazuje SHA-256 kontrolni zbir.
