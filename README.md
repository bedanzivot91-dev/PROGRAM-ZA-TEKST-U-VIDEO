# PROGRAM ZA TEKST U VIDEO

Ovo je kompletan program **Muzicki Spot Studio Free v15.6.0** za pravljenje videa od pesme i teksta.

## Instalacija na Windowsu

1. Na GitHubu klikni **Code → Download ZIP**.
2. Raspakuj ceo ZIP u folder.
3. Pokreni **INSTALIRAJ-PROGRAM.bat**.
4. Skripta automatski sastavlja svih 12 delova installera, proverava SHA-256 i pokreće installer.

Ne pokreci nijedan fajl koji se zavrsava sa `.part001`, `.part002` itd. To su delovi jednog EXE fajla i ne mogu pojedinacno da se instaliraju.

Ako zelis portable verziju, pokreni **SASTAVI-PROGRAM-PORTABLE.bat** nakon sto se program sastavi.

Izvorni kod, testovi i dokumentacija nalaze se u folderu `SOURCE`.
